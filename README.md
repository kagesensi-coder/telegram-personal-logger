# Telegram Personal Logger Bot

Персональный юзербот для сохранения удаленных и измененных сообщений/медиафайлов в Telegram с автоматической очисткой базы данных и круглосуточным запуском на хостинге.

---

## 📌 Основной функционал
- 📥 Логирование удаленных и отредактированных сообщений в Telegram.
- 📁 Сохранение всех медиафайлов (фото, видео, голосовые сообщения, кружочки).
- 🧹 Автоматическая очистка SQLite базы от старых записей (`days_to_keep=30`) и сжатие (`VACUUM`) при старте для экономии дискового пространства (лимит 512MB).
- 🔔 Гибкая отправка уведомлений в специальную группу или чат.

---

## 🛠️ Требования
- **Python** 3.10 или новее
- Аккаунт **GitHub**
- Учетная запись на **bot-hosting.net** (Pterodactyl)

---

## 🚀 Пошаговая инструкция по запуску

### 1. Подготовка локального проекта и загрузка на GitHub

Открой терминал в папке проекта на своем компьютере и выполни команды по порядку:

```bash
# 1. Инициализация Git (если репозиторий еще не создан локально)
git init

# 2. Добавление всех файлов проекта под отслеживание
git add .

# 3. Фиксация первого коммита
git commit -m "Initial commit: Telegram Personal Logger"

# 4. Переименование главной ветки в main (если требуется)
git branch -M main

# 5. Привязка удаленного репозитория GitHub (замени URL на свой)
git remote add origin https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/telegram-personal-logger.git

# 6. Отправка кода на GitHub
git push -u origin main
```

---

### 2. Подключение и развертывание на Bot-Hosting.net

1. Перейди в панель **bot-hosting.net** и войди в свою учетную запись.
2. Создай новый сервер:
   - **Environment/Language:** Python.
   - **Startup File:** `logger.py`
3. Подключи свой GitHub-репозиторий в настройках сервера (раздел **GitHub / Repository**).
4. Перейди в раздел **Variables** (Переменные окружения) и добавь необходимые данные Telegram API:
   - `API_ID` — твой Telegram API ID (получать на [my.telegram.org](https://my.telegram.org))
   - `API_HASH` — твой Telegram API Hash
   - `SESSION` — имя файла сессии (например, `personal_logger`)

---

### 3. Запуск и авторизация

1. Перейди во вкладку **Console** (Консоль).
2. Нажми кнопку **Start** или **Restart**.
3. При первом запуске скрипт попросит ввести номер телефона и код подтверждения из Telegram прямо в консоли.
4. После успешной авторизации сессия сохранится, и в консоли появятся строки:
   ```text
   [CleanUp] Удалено старых записей: 0. База данных сжата.
   INFO Подключение к Telegram...
   INFO Существующая сессия авторизована.
   INFO Юзербот запущен. Ctrl+C для остановки.
   ```

---

## 🔄 Как обновлять код бота на хостинге

Каждый раз, когда ты вносишь изменения в файлы проекта (например, в `logger.py`), выполняй эти 3 команды в терминале на компьютере:

```bash
git add .
git commit -m "Описание внесенных изменений"
git push
```

После успешного выполнения `git push` зайди в панель **bot-hosting.net** и нажми кнопку **Restart** (Перезапустить).
