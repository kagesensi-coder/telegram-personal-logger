# Telegram Personal Logger Bot

Персональный юзербот для сохранения удаленных и измененных сообщений/медиафайлов в Telegram с автоматической очисткой базы данных и возможностью локального или круглосуточного запуска на хостинге.

---

## 📌 Основной функционал

- 📥 Логирование удаленных и отредактированных сообщений в Telegram.
- 📁 Сохранение всех медиафайлов (фото, видео, голосовые сообщения, кружочки).
- 🧹 Автоматическая очистка SQLite базы от старых записей (`days_to_keep=30`) и сжатие (`VACUUM`) при старте для экономии дискового пространства.
- 🔔 Гибкая отправка уведомлений в специальную группу или чат.

---

## 🛠️ Требования

- **Python** 3.10 или новее
- Аккаунт **Telegram** и API ключи (`API_ID`, `API_HASH` с [my.telegram.org](https://my.telegram.org))
- Аккаунт **GitHub** (для сохранения кода или развертывания на хостинге)

---

## 🚀 Варианты установки и запуска

Выбери подходящий вариант использования:

---

### 🔹 Вариант 1: Локальный запуск (на компьютере)

Этот вариант подходит, если тебе нужно запускать бота периодически на своем ПК.

#### 1. Клонирование репозитория и установка зависимостей
```bash
# Клонируй репозиторий 
git clone https://github.com/kagesensi-coder/telegram-personal-logger.git
cd telegram-personal-logger

# Создай и активируй виртуальное окружение (опционально, но рекомендуется)
python -m venv venv

# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

# Установи необходимые библиотеки
pip install -r requirements.txt
```

#### 2. Настройка переменных окружения
Создай файл `.env` в корневой папке проекта и добавь свои данные:
```env
API_ID=1234567
API_HASH=your_api_hash_here
SESSION=personal_logger
```

#### 3. Запуск бота
```bash
python logger.py
```
*При первом запуске введи номер телефона и код подтверждения из Telegram.*

---

### 🔹 Вариант 2: Запуск 24/7 на хостинге (bot-hosting.net / Pterodactyl)

Этот вариант подходит для круглосуточной работы бота без необходимости держать включенным свой ПК.

#### 1. Загрузка кода в GitHub
Открой терминал в папке проекта и отправь код в свой репозиторий:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/telegram-personal-logger.git
git push -u origin main
```

#### 2. Настройка сервера на Bot-Hosting.net
1. Зайди в панель управления **bot-hosting.net**.
2. Создай новый сервер:
   - **Environment/Language:** Python.
   - **Startup File:** `logger.py`
3. Перейди в раздел **GitHub / Repository** и подключи свой репозиторий.
4. В разделе **Variables** (Переменные окружения) добавь:
   - `API_ID` — твой Telegram API ID
   - `API_HASH` — твой Telegram API Hash
   - `SESSION` — имя файла сессии (например, `personal_logger`)

#### 3. Запуск и первая авторизация
1. Открой вкладку **Console** (Консоль) и нажми **Start**.
2. Введи номер телефона и код из Telegram прямо в консоли хостинга при первом старте.
3. После авторизации бот будет работать непрерывно 24/7.

---

## 🔄 Как обновлять код бота

Если ты изменил код (например, `logger.py`), обнови его в GitHub:

```bash
git add .
git commit -m "Обновление функционала"
git push
```

- **При локальном запуске:** Нажми `Ctrl+C` в терминале и запусти бота снова (`python logger.py`).
- **При запуске на хостинге:** Нажми кнопку **Restart** в панели управления.
